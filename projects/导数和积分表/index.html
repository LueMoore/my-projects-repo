DERIVATIVES & INTEGRALS

一、导数公式

① 基本初等函数导数

(C)′ = 0
(xμ)′ = μ·xμ−1
(ax)′ = ax·ln a a>0, a≠1
(ex)′ = ex
(logax)′ = 1x·ln a
(ln x)′ = 1x  ，  (ln|x|)′ = 1x
(sin x)′ = cos x
(cos x)′ = −sin x
(tan x)′ = sec2x = 1cos2x
(cot x)′ = −csc2x = −1sin2x
(sec x)′ = sec x·tan x
(csc x)′ = −csc x·cot x

② 反三角函数导数

(arcsin x)′ = 1√(1−x²)
(arccos x)′ = −1√(1−x²)
(arctan x)′ = 11+x²
(arccot x)′ = −11+x²
(arcsec x)′ = 1|x|√(x²−1)
(arccsc x)′ = −1|x|√(x²−1)

③ 双曲函数导数

(sinh x)′ = cosh x
(cosh x)′ = sinh x
(tanh x)′ = sech2x = 1cosh2x
(coth x)′ = −csch2x
(arsinh x)′ = 1√(x²+1)
(arcosh x)′ = 1√(x²−1) x>1
(artanh x)′ = 11−x² |x|<1

④ 求导运算法则

(u ± v)′ = u′ ± v′
(Cu)′ = C·u′
(uv)′ = u′v + uv′
(u/v)′ = u′v − uv′v² v≠0
复合：{f[g(x)]}′ = f′(u)·g′(x) u=g(x)
反函数：[f−1(y)]′ = 1f′(x)
参数方程：dydx = ψ′(t)φ′(t) x=φ(t), y=ψ(t)
隐函数：F(x,y)=0 ⇒ dydx = −FxFy
对数求导：(ln y)′ = y′y

⑤ 高阶导数

(xn)(n) = n!
(ex)(n) = ex
(ax)(n) = ax·(ln a)n
(sin x)(n) = sin(x + n·π2)
(cos x)(n) = cos(x + n·π2)
(ln x)(n) = (−1)n−1·(n−1)!xn
(1x)(n) = (−1)n·n!xn+1
莱布尼茨：(uv)(n) = Σk=0n Cnk u(n−k)v(k)

二、积分公式

① 基本积分公式

∫ 0 dx = C
∫ 1 dx = x + C
∫ xμ dx = xμ+1μ+1 + C μ≠−1
∫ 1x dx = ln|x| + C
∫ ax dx = axln a + C
∫ ex dx = ex + C
∫ sin x dx = −cos x + C
∫ cos x dx = sin x + C
∫ sec2x dx = tan x + C
∫ csc2x dx = −cot x + C
∫ sec x·tan x dx = sec x + C
∫ csc x·cot x dx = −csc x + C
∫ sinh x dx = cosh x + C
∫ cosh x dx = sinh x + C

② 三角相关积分

∫ tan x dx = −ln|cos x| + C
∫ cot x dx = ln|sin x| + C
∫ sec x dx = ln|sec x + tan x| + C
∫ csc x dx = ln|csc x − cot x| + C
∫ sin2x dx = x2 − sin 2x4 + C
∫ cos2x dx = x2 + sin 2x4 + C
∫ tan2x dx = tan x − x + C
∫ cot2x dx = −cot x − x + C
∫ sec3x dx = 12(sec x·tan x + ln|sec x + tan x|) + C
∫ dx1+cos x = tanx2 + C
∫ dx1+sin x = tan x − sec x + C
∫ dxsin x·cos x = ln|tan x| + C

③ 含参数 a 的积分

∫ dxa²+x² = 1a arctanxa + C
∫ dxa²−x² = 12a ln|a+xa−x| + C
∫ dxx²−a² = 12a ln|x−ax+a| + C
∫ dx√(a²−x²) = arcsinxa + C
∫ dx√(x²±a²) = ln|x + √(x²±a²)| + C
∫ dxx√(x²−a²) = 1a arccosax + C x>a
∫ √(a²−x²) dx = x2√(a²−x²) + a²2 arcsinxa + C
∫ √(x²+a²) dx = x2√(x²+a²) + a²2 ln|x+√(x²+a²)| + C

④ 常用分部积分结果

∫ ln x dx = x·ln x − x + C
∫ x·ex dx = (x−1)ex + C
∫ x·sin x dx = −x·cos x + sin x + C
∫ x·cos x dx = x·sin x + cos x + C
∫ x·ln x dx = x²2ln x − x²4 + C
∫ arctan x dx = x·arctan x − 12ln(1+x²) + C
∫ arcsin x dx = x·arcsin x + √(1−x²) + C
∫ eaxsin bx dx = eaxa²+b²(a·sin bx − b·cos bx) + C
∫ eaxcos bx dx = eaxa²+b²(a·cos bx + b·sin bx) + C

⑤ 积分方法

第一换元（凑微分）：∫ f[φ(x)]φ′(x) dx = ∫ f(u) du = F(u) + C
第二换元：x = φ(t) ⇒ ∫ f(x) dx = ∫ f[φ(t)]·φ′(t) dt
分部积分：∫ u dv = u·v − ∫ v du
选 u 顺序口诀：反 → 对 → 幂 → 三 → 指
有理函数：先化为部分分式，再逐项积分
三角有理式：万能代换 t = tan(x/2)
根式：√(a²−x²) 用 x=a·sin t；√(a²+x²) 用 x=a·tan t
